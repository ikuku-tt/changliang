# 常亮

常亮是一个 macOS 菜单栏工具。点开咖啡杯，打开「保持唤醒」，屏幕就会在电脑闲置时保持点亮。需要定时轻移鼠标时，可以把间隔设为 1 到 30 分钟，默认 5 分钟。

## 安装与使用

支持 macOS 13 及以上版本，适用于 Apple 芯片和 Intel 芯片的 Mac。

1. 下载 `Changliang.dmg`，打开镜像，将「常亮」拖入「应用程序」。[下载最新版本](https://github.com/ikuku-tt/changliang/releases/latest)
2. 从「应用程序」打开「常亮」，点击菜单栏的咖啡杯，开启「保持唤醒」。再次关闭开关即可恢复系统的闲置休眠设置。
3. 要使用鼠标轻移，点「允许移动鼠标…」，在系统设置 → 隐私与安全性中允许「常亮」控制鼠标。该权限在 macOS 27.0 中显示为「设备控制和数据访问」，在较早版本中显示为「辅助功能」。

如果系统开关已经打开，菜单仍显示「鼠标轻移等待授权」，请从咖啡杯菜单点「退出」，再打开同一份「常亮」并开启「保持唤醒」。

屏幕常亮可以单独使用。授予鼠标权限后，常亮每 20 秒检查一次空闲状态，在指针原位发送活动事件，到了选定间隔才轻移 2 到 5 个点。最近 3 秒有输入或鼠标按键仍按下时，会跳过当次事件。手动锁屏、休眠或切换用户时会暂停，回到活动桌面后继续。

## 从源码构建

在 Mac 上安装带有 macOS 13 或更新版本 SDK 的 Xcode 或 Xcode 命令行工具，然后在仓库根目录运行构建脚本。

```sh
./build.sh
```

脚本会编译双架构的 App、生成图标，并将安装镜像写入 `build/Changliang.dmg`。v1.0 的下载版和本地构建均使用 ad hoc 签名。如果 macOS 的首次打开检查拦下下载版，可从源码构建。

单文件源码也支持用 Swift 直接运行。

```sh
swift KeepAwake.swift
```
